# Poetry Web Page

A clean and responsive poetry web page built using **JavaScript**, **HTML**, **CSS**, and **Bootstrap**.

## Tech Stack
- **JavaScript** — Interactivity and dynamic page behavior
- **HTML5** — Semantic structure and content layout
- **CSS3** — Custom styling, spacing, and typography
- **Bootstrap** — Responsive layout and UI components

## Features
- Responsive design across screen sizes
- Readable poetry formatting and clean visual presentation
- Interactive elements powered by JavaScript

## How to Run Locally
1. Clone or download the repository.
2. Open `index.html` in a web browser.
